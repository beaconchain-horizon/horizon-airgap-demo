# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities to: gamma.mahdii@gmail.com

Do NOT open a public GitHub issue for security issues.

Response times:
- 48 hours: acknowledgment
- 7 days: assessment
- 30 days: fix plan

## Scope

This repository demonstrates Horizon Core Air-Gap capability.
Only the demo harness and precompiled binaries are published here.

For the full security policy, see:
https://github.com/beaconchain-horizon/horizon-security-assessment/blob/main/SECURITY.md

## Air-Gap Security Properties

- Full operation without internet connectivity
- Local ECDSA P-256 signing
- Immutable ledger with tamper detection
- Only new data transfers on reconnect
- No external calls in Air-Gap mode
